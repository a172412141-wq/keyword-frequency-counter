# Amazon Ads Bulk 分析精华

> 状态：原 Bulk 广告诊断工具已下线。本文只保留可复用的数据思路、诊断框架和工程经验，不保留可执行工具。

## 1. 先稳住数据口径

Amazon Ads Bulk 不能默认为一张干净的单表。更稳健的读取方法是：

1. 同时识别 `Sponsored Products Campaigns`、`SP Search Term Report` 和 `Portfolios`，并兼容旧版单表。
2. 不依赖工作表名；先扫描前 30 行，用表头组合判断表类型和表头行。
3. 遇到 Amazon 错误声明为 `A1:A1` 的工作表维度时，先重置 dimension，再以流式方式读取。
4. 建立表头别名层，把 Campaign、Ad Group、Portfolio、ASIN、SKU 的正式列与 informational-only 列归一。
5. 生成结果前先验证必需指标、筛选字段和搜索词关联键，数据不完整时应停止，不要输出“看似完整”的误导报告。

## 2. 筛选语义要跟字段性质一致

- ASIN、SKU、Portfolio ID/Name：适合精确多选。
- Campaign、Ad Group：名称往往含有前后缀和分组标记，适合多选“包含”匹配。
- 搜索词：应通过 Campaign + Ad Group 联合键与广告数据关联，避免仅按名称单列关联造成窜数。
- 多选值必须去重、标准化大小写和空格，并将实际筛选口径写进结果元数据。

## 3. 诊断不是堆指标，而是串起因果链

基础指标只是起点：

| 指标 | 口径 | 解读 |
| --- | --- | --- |
| CTR | Clicks / Impressions | 广告触达后的点击吸引力 |
| CPC | Spend / Clicks | 获取一次访问的价格 |
| CVR | Orders / Clicks | 点击后的转化效率 |
| ACoS | Spend / Sales | 广告销售的投入比 |
| ROAS | Sales / Spend | 每单位投入带来的销售额 |
| AOV | Sales / Orders | 广告订单的平均价值 |
| CPM | Spend / Impressions × 1000 | 获取曝光的成本 |

更有价值的诊断顺序是：

1. **流量是否来了**：曝光、竞价、广告位分布。
2. **流量是否点击**：CTR 与 CPC 一起看，区分素材/词包问题和竞价问题。
3. **点击是否转化**：CVR、Orders、Sales 与搜索词意图联动。
4. **转化是否盈利**：ACoS/ROAS 要与真实毛利、客单价和退货成本结合，不能单独作为关停标准。
5. **结构是否健康**：比较花费份额与销售份额，找出“高花费、低产出”的结构性缺口。

## 4. 报告应围绕决策层级组织

最有价值的八类视图为：

1. Portfolio 预算与产出：预算、活动状态、花费、订单、销售和效率。
2. 原始 Bulk 子集：保留筛选后的可追溯明细。
3. Bidding Adjustment：拆解广告位溢价与投放结果。
4. 广告位可视化：比较 Top of Search、Product Pages 等位置的成本与转化。
5. 搜索词明细：让流量意图可查、可排序、可追溯。
6. 全部搜索词词频：找出主题和高频意图。
7. 无订单搜索词词频：找出消耗型词根。
8. 否定词候选库：仅作为人工复核队列，不应自动批量否定。

## 5. Excel 产物的可用性细节

- 保留样式、冻结窗格、自动筛选和图表，因为这些是业务阅读体验的一部分。
- 公式引用实际数据范围，避免整列引用造成 Excel/WPS 重算缓慢。
- 同时支持“带公式”和“静态值”产物：前者便于继续分析，后者适合分享和稳定打开。
- 静态化不能只删除公式；应在保留格式的前提下计算并回写支持的公式结果。
- 模板必须脱敏：删除真实广告数据、外部链接和不兼容的图表外部数据引用。

## 6. 大文件工具的工程经验

- 将“读取校验”和“生成报告”拆成两步。
- 用文件 SHA-256 作为缓存键，在单进程内保留小型 LRU 缓存；生成阶段优先复用已解析对象。
- 缓存失效时必须明确告知用户“正在重新读取”，而不是卡在假进度上。
- 长任务的进度语义应稳定为：上传 → 读取校验 → 生成产物 → 准备下载。
- 广告文件含有敏感的 Campaign、SKU、ASIN、Spend、Sales 和 Search Term 数据；大文件默认本地处理，托管处理必须单独获得授权。

## 7. 可迁移的最后原则

1. 先验证口径，再计算指标。
2. 先保留明细可追溯性，再做聚合和可视化。
3. 把指标放进因果链，不用单指标代替经营判断。
4. 把否定词、调价、关停等高影响动作保留给人工复核。
5. 工具可以下线，但数据口径、诊断次序、隐私原则和工程经验应继续复用。
