# Weekly Doc Workflow

## Fetching

- Prefer user identity because weekly docs usually live in personal or shared Drive space.
- Search Drive with recent edit filters when the user gives only a date or theme.
- Fetch outline before reading full or keyword-scoped content.
- Use keyword scope for large docs when the question names inventory, replenishment, returns, cash flow, or expansion.

## Extraction

Scan for:

- object: SKU, parent, product line, category, platform, inventory pool, or project;
- stage: `0-10`, `10-30`, `30-60`, `60-100`, or unknown;
- KPI: true contribution margin, GMV, return rate, stockout, coverage days, turnover, cash cycle;
- red lines: negative contribution margin, stockout risk, return-rate abnormality, worsening turnover, replenishment cash gap, unstable main SKU expansion;
- action: continue testing, optimize, replenish, pause, expand, clean up, stop loss.

## Promotion Discipline

Archive raw notes first. Promote only reusable rules into future Fang workflow. Keep one-off meeting observations under `待复验`.
